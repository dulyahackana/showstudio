## Stubbed (real interface, simple implementation)

| Area               | Now                                                                                    | Production                                                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Identity           | Persona dev login (HMAC session)                                                       | OIDC SSO (Entra / Okta / Keycloak); roles from IdP groups                                                                    |
| Workspace          | One static tenant and people directory                                                 | Multi-tenant (tenant id on every row, row-level security); directory and groups from the IdP (SCIM)                          |
| Device identity    | HMAC token per device                                                                  | mTLS with per-device certificates; provisioning ceremony; rotation                                                           |
| Signing key        | RSA key file under `DATA_DIR`                                                          | KMS/HSM-held key, rotation, multiple trusted keys on devices                                                                 |
| Blob storage       | Content-addressed filesystem                                                           | S3/GCS behind the same `BlobStore`; signed URLs instead of `?access_token=`                                                  |
| Transport          | WebSocket gateway in the API process                                                   | Sharded gateway or MQTT broker (EMQX / AWS IoT Core)                                                                         |
| Park edge          | Devices talk to the cloud directly; operator console (local e-stop, RUN via the cloud) | On-site edge gateway caching bundles and running the show controller; offline launch; console E-STOP wired to the safety PLC |
| Live updates in UI | 1 s polling (TanStack Query)                                                           | Server-sent events / WebSocket push                                                                                          |
| Concurrent editing | Optimistic locking + reload                                                            | Real-time co-editing (CRDT/Yjs) per track                                                                                    |
| Observability      | Logs + metrics endpoint                                                                | OpenTelemetry traces → Grafana/Datadog; alerting on device offline, deploy stuck, e-stop                                     |
| Infrastructure     | docker-compose                                                                         | Terraform; dev/staging/prod; blue-green API deploys                                                                          |

## Gaps and mitigations

| Gap                                               | Risk                                           | Mitigation                                                                                                                                                             |
| ------------------------------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Functional safety certification                   | Injury; cannot legally operate                 | Safety owner from day one; HARA/FMEA; hard-wired limits and e-stop independent of software; IEC 61508 / ISO 13849, ASTM F24; validator treated as safety-relevant code |
| Acceleration / jerk limits                        | Mechanical stress, overshoot on real actuators | Add per-joint accel/jerk limits to the definition and validator; ease profiles already reduce them                                                                     |
| Collision checks between figures and with scenery | Figures hitting each other or the set          | Footprint boxes today; next: swept-volume checks in a robotics simulator (MuJoCo / Isaac Sim) as a publish gate                                                        |
| Game-engine physics ≠ real dynamics               | Show passes in sim, fails on hardware          | The Godot twin plays keyframes (visual and protocol twin); dynamics validation in a robotics sim; HIL test rig before the park                                         |
| Bun runtime maturity                              | Runtime bugs in a younger runtime              | Pinned version (`packageManager`, Docker tag, CI); the API refuses Bun < 1.4 (PGlite crash found here); the code uses Node APIs, so Node stays a fallback runtime      |
| Industrial network security (IEC 62443)           | Compromised network moves real machines        | Segmented show-control network; devices accept only signed bundles; no inbound internet; mTLS                                                                          |
| Time sync on site                                 | Motion/light/audio drift                       | PTP (IEEE 1588) / SMPTE timecode; devices start on a shared clock                                                                                                      |
| Controller firmware updates                       | Bricked or mismatched fleet                    | A/B partitions, staged rollout (one device → zone → park), automatic rollback; definition revision tied to firmware                                                    |
| Upload attack surface                             | Malicious or huge files                        | Magic-byte checks and size caps today; add sandboxed parsing worker, malware scan, signed URLs                                                                         |
| Data loss                                         | Lost shows and history                         | Immutable artifacts; managed Postgres backups with tested restore; agreed RPO/RTO                                                                                      |
| Supply chain                                      | Compromised dependency                         | Lockfile, Trivy image scan in CI; add Renovate, SBOM (Syft), CodeQL                                                                                                    |
| Scale (many parks, thousands of devices)          | Gateway bottleneck                             | Stateless API; sharded gateway / MQTT; per-park edge cache; CDN for blobs                                                                                              |
